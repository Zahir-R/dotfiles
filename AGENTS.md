# AGENTS.md — NixOS Flake Infrastructure

## Overview

Flake-based NixOS config (`nixos-unstable`) managing 4 machines, single user (`zahir`), with home-manager integration.

## Hosts

| Host | Hostname | Role | Profiles |
|------|----------|------|----------|
| `gamedev` | `gamedev` | Game dev workstation | desktop, nvidia, gamedev (Unity, Godot) |
| `webwork` | `webwork` | Full-stack dev workstation | desktop, nvidia, appdev (Android), databases |
| `weblight` | `web-light` | Light web dev | desktop, webdev (Chromium), databases |
| `microserver` | `micro-server` | Headless server | (none — minimal, no docs) |

## Deploy

All hosts are `x86_64-linux`.

```bash
# rebuild any host
sudo nixos-rebuild switch --flake /etc/nixos#<hostname>

# home-manager runs as part of nixos-rebuild (integrated via sharedModules)
# standalone home-manager switch is NOT used
```

The user's zsh config defines `zreload [hostname]` (defaults to current hostname) as an alias for the above rebuild command + `systemctl restart systemd-hostnamed`.

## Flake structure

```
/etc/nixos/
├── flake.nix              # entrypoint — defines all 4 nixosConfigurations
├── flake.lock
├── config/hypr/           # Hyprland dotfile (hyprland.lua)
├── config/nvim/           # Neovim config (LazyVim)
├── hosts/
│   └── <host>/default.nix # per-host: hostname, boot loader, swap, hw-specific
├── modules/
│   └── core/base.nix      # shared: timezone, locale, flakes, zsh, fonts, base pkgs
├── profiles/              # composable role profiles (pick & mix)
│   ├── desktop/           # Hyprland, SDDM (Catppuccin), PipeWire, desktop apps
│   ├── nvidia/            # NVIDIA: modesetting, stable driver, no power mgmt
│   ├── databases/         # PostgreSQL 16, MariaDB, Redis
│   ├── gamedev/           # Unity Hub, Godot 4 Mono (Wayland+NVIDIA flags)
│   ├── appdev/            # Android Studio, SDK tools
│   └── webdev/            # Chromium, inotify tweaks
├── users/zahir/
│   ├── user.nix            # user decl (zahir: zsh, wheel+groups)
│   ├── home.nix            # home-manager: Alacritty, zoxide, starship, zsh config, direnv, cursor theme, Neovim/Hyprland dotfiles
│   └── starship.toml       # starship prompt config
```

## Key details

- **Home-manager** is wired into `sharedModules` in `flake.nix` — runs during `nixos-rebuild`, not standalone.
- **`sharedModules`** list in `flake.nix:19-28` applies to ALL hosts: `base.nix`, `user.nix`, home-manager.
- **Profiles** in `profiles/` are composable, optional role modules. A host picks which profiles to enable.
- **No `shell.nix` or `devShell`** — all packages are installed system-wide via `environment.systemPackages`. Per-project runtimes (Node, Java, .NET) should be handled via per-project `nix-shell`/`devShell`, NOT added to profiles.
- Profiles contain heavyweight apps or persistent services only (game engines, databases, desktop environments, IDEs).
- `opencode` is included system-wide (in `core/base.nix`).
- **Android** toolchain is in `profiles/appdev/` (only on `webwork`). Uses `android-nixpkgs` overlay, expects SDK at `/home/zahir/Android/Sdk`.
- **Godot** on gamedev has explicit NVIDIA/Wayland wrapper flags in `profiles/gamedev/engines.nix`.
- **No README** exists — `AGENTS.md` is the only doc.

## Style / conventions

- Configs use `{ ... }: { ... }` pattern (no explicit `lib` or `pkgs` unless needed).
- Hardware configs are host-specific and live under `hosts/<name>/hardware-configuration.nix` (auto-generated by `nixos-generate-config`).
- `system.stateVersion = "26.05"` everywhere.
- `nixpkgs.config.allowUnfree = true` in `base.nix`.
- `boot.loader` varies by host: gamedev+webwork use systemd-boot (EFI), weblight+microserver use grub (BIOS).
